# Student Performance Analysis

## Objective
Analyze Portuguese student performance data to understand factors affecting academic outcomes.

## Dataset
Portuguese student performance dataset (student-por.csv)

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Key Analysis
- Data loading and validation
- Summary statistics
- Correlation analysis between study habits and grades

## Insights
Early academic performance (G1, G2) strongly predicts final grades (G3).
